PROJETO: BROOKLYN & FIFTH — Barber & Beauty House

Crie um site demonstrativo premium, responsivo e visualmente marcante para um estabelecimento fictício chamado BROOKLYN & FIFTH, reunindo duas experiências completamente diferentes dentro do mesmo site:

* BROOKLYN — Barbershop
* FIFTH — Beauty Salon

O projeto será utilizado como demonstração comercial da Manhattan Studios para apresentar a barbearias e salões de beleza o nível de site que pode ser desenvolvido para seus negócios.

O resultado deve parecer um projeto digital desenvolvido por uma agência criativa de alto nível, e não um template, landing page SaaS ou site facilmente reconhecível como gerado por IA.

Priorize:

1. direção artística;
2. identidade;
3. experiência mobile;
4. criatividade de layout;
5. microinterações;
6. performance;
7. acessibilidade.

⸻

1. STACK

Utilize:

* Next.js 15+ com App Router;
* TypeScript;
* Tailwind CSS;
* React Server Components sempre que possível;
* componentes client-side somente quando necessários para interações;
* Framer Motion para animações quando realmente agregar valor;
* Lucide apenas para ícones utilitários simples;
* next/image para imagens;
* next/font ou carregamento otimizado das fontes;
* ESLint;
* Prettier.

Não adicione backend, banco de dados, autenticação ou integrações externas desnecessárias nesta demonstração.

O sistema de agendamento será apenas uma simulação front-end.

Não simule APIs ou serviços externos inexistentes.

3. TIPOGRAFIA — EXTREMAMENTE IMPORTANTE

A tipografia é parte fundamental da identidade do projeto.

NÃO utilize a combinação de fontes típica de sites gerados por IA.

Evite usar como fonte principal:

* Inter;
* Geist;
* Arial;
* Roboto;
* Open Sans;
* Poppins;
* Montserrat;
* ou qualquer outra escolha genérica apenas por conveniência.

Não quero que todo o site utilize uma única sans-serif moderna com diferentes pesos.

Pesquise e selecione fontes diferentes, expressivas e adequadas à direção artística de cada universo.

As fontes devem possuir licenciamento apropriado para uso web.

Tipografia Brooklyn

Buscar uma combinação de:

* display condensada;
* grotesca;
* tipografia inspirada em pôsteres, jornais ou sinalização urbana;
* fonte secundária altamente legível para textos.

Títulos podem possuir letras estreitas, fortes e altas.

Utilize recursos como:

* uppercase;
* tracking;
* tamanhos extremos;
* composição vertical;
* texto seguindo elementos gráficos;
* palavras parcialmente sobrepostas às fotografias.

A tipografia deve contribuir para a sensação de Brooklyn industrial/editorial.

Tipografia Fifth

Utilizar uma linguagem completamente diferente.

Buscar:

* serifas editoriais expressivas;
* serifas de alto contraste;
* itálicos elegantes;
* fontes display inspiradas em revistas de moda;
* sans-serif secundária discreta para informações funcionais.

A estética deve lembrar a composição de uma revista de moda ou coluna social de Manhattan.

Explore:

* manchetes enormes;
* itálicos;
* números;
* pequenas legendas;
* datelines;
* capitulares;
* alinhamentos assimétricos;
* texto vertical;
* composições de jornal.

Regra

Brooklyn e Fifth NÃO devem compartilhar exatamente a mesma hierarquia tipográfica.

A troca entre os dois lados deve ser perceptível inclusive pela tipografia.

Não escolher fontes apenas porque são populares em projetos de UI.

A fonte precisa possuir personalidade.

28. PROCESSO DE IMPLEMENTAÇÃO

Antes de começar a programar:

1. analise todo este briefing;
2. defina arquitetura das páginas;
3. defina sistema visual Brooklyn;
4. defina sistema visual Fifth;
5. selecione conscientemente as fontes;
6. defina quais componentes serão compartilhados;
7. planeje responsividade;
8. planeje animações;
9. só então implemente.

Durante o desenvolvimento, não simplifique elementos criativos importantes apenas porque um componente convencional seria mais rápido.

A navalha, o secador, o jornal das profissionais, a entrada dividida, a galeria de clientes e a transição Brooklyn/Fifth são elementos centrais do conceito.

Se algum efeito complexo não puder ser implementado exatamente como imaginado, crie uma alternativa visual elegante que preserve a ideia original em vez de substituí-lo por um card comum.

29. RESULTADO ESPERADO

Ao final, quero que um proprietário de barbearia ou salão consiga abrir esse site e imediatamente imaginar seu próprio negócio utilizando algo semelhante.

A experiência deve comunicar:

identidade → profissionais → serviços → resultados → confiança → localização → agendamento.

BROOKLYN deve parecer uma barbearia de personalidade forte no Brooklyn.

FIFTH deve parecer um beauty salon que poderia aparecer em um editorial de Manhattan.

Os dois devem claramente pertencer à mesma marca, mas não devem parecer o mesmo template com cores diferentes.

A tipografia, composição, fotografia e direção artística devem ser suficientemente distintas para que a mudança entre os dois universos seja imediatamente percebida.

O resultado final deve ter aparência de um projeto digital customizado e desenvolvido especificamente para a marca BROOKLYN & FIFTH, servindo como showcase da capacidade criativa da Manhattan Studios.
